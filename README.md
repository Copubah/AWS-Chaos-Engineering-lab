# AWS ResilienceLab

## Project Overview

AWS ResilienceLab is a practical chaos engineering
project designed to test the resilience of AWS
infrastructure through controlled failure experiments.

## Objectives

- Build highly available AWS infrastructure.
- Deploy an application across multiple Availability Zones.
- Simulate infrastructure failures.
- Monitor failures using Amazon CloudWatch.
- Implement automatic recovery mechanisms.
- Measure Mean Time to Recovery (MTTR).
- Automate infrastructure using Terraform.

## Technology Stack

- AWS EC2
- AWS VPC
- Application Load Balancer
- Auto Scaling
- AWS Fault Injection Service
- Amazon CloudWatch
- Python
- Terraform
- Docker
